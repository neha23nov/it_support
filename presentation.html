Slide 02 / The Challenge

Business Problem & Objectives

The Operational Pain

  • • Repetitive ticket fatigue (Guest Wi-Fi, VPN renewals, password resets).
  • • High risk of policy breaches (employees forwarding phishing emails).
  • • Ambiguous requests stalling technician queues (*"its not working"*).
  • • Cross-department boundary confusion (Finance vs IT expense access).

Agent Solution Mandate

  • • Instant Self-Service: Immediate guidance without IT ticket overhead.
  • • Zero Hallucination: Answers grounded strictly in official policies.
  • • Active Guardrails: Stops dangerous actions before they spread.
  • • Compliance Trail: Every action and source cited for auditability.
Slide 03 / Ground Truth

Knowledge Base & Policy Grounding

Strictly following the assignment constraint: "Do not invent policies or information that isn't grounded in one of these sources."

KB-01: Password Reset

Self-service portal anytime. Manual unlock required only if locked out after 5 attempts.

KB-02: VPN Access

Automatic for FTEs; 90-day renewal. Contractors require manager approval via form.

KB-03 & Asset Policy

4-year refresh cycle. Laptops eligible for replacement after 3 years or verified hardware failure.

KB-04: Software Catalog

Standard software self-installed. Non-catalog requires IT Security review (3-5 business days).

KB-07: Guest Wi-Fi

Generated at front-desk kiosk; 24-hour validity. Zero IT ticket needed.

KB-09: Security Incidents

Report to security@veridian-corp.example immediately. DO NOT forward to teammates.

Slide 05 / Triage Engine

Agent Decision Matrix & Guardrails

1. Direct Resolution

Resolves standard self-service requests immediately.

"Generate guest Wi-Fi at the front-desk kiosk; 24h validity. No ticket needed." (KB-07)
2. Targeted Clarification

Refuses to guess on vague or underspecified requests.

"REQ-15: 'hey can you help, its not working' -> Asks device type, error code, and onset time."
3. Security Interception

Catches dangerous behaviors like forwarding phishing emails.

"REQ-08: DO NOT forward to teammates! Auto-flagged to security@veridian-corp.example." (KB-09)
4. Structured Escalation

Creates tickets routed to the exact department with SLAs.

"REQ-04: Non-catalog software -> Ticket opened for IT Security review (3-5 day SLA)." (KB-04)
Slide 06 / Edge Cases

Handling Cross-Departmental Boundaries

1
IT vs. Finance Boundaries (KB-08)

Access to expense software is granted by Finance, not IT. IT only assists with credentials once an account exists. The agent clarifies ownership instead of creating useless tickets.

2
Contractor Compliance vs. Full-Time Employees (KB-02)

FTEs get automatic VPN credentials. Contractors require manager approval submitted via the formal access request form.

3
Hardware Lifecycle vs. Early Failure (KB-03 & Precedent TK-1043)

Aman Gupta (2-year laptop) gets screen diagnostics/repair, not replacement. Aditi Sharma (3.5-year dead laptop) qualifies for replacement under verified failure.
